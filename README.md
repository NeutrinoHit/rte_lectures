# Распространение света в среде

Русский курс лекций по 45 минут. Десятичный разделитель — точка,
в том числе в русском тексте и подписях. Материал создаётся и обсуждается небольшими
последовательными фрагментами в одном исходнике лекции. Подробные выкладки
расположены в табах и продолжают друг друга.

## Лекция 1. Уравнение переноса

Длина волны фиксируется в начале. Во всех формулах используются
монохроматические величины без спектральных индексов.

Вывод RTE из одного баланса фотонов в неподвижном объёме (поток через границу,
поглощение, уход и приход при рассеянии, источник), сохранение числа фотонов и точные следствия
уравнения без приближений: однородное поглощение выделяется множителем
$e^{-\alpha t}$, а центр и ковариация направленной вспышки подчиняются
замкнутым уравнениям для глобальных моментов. Они совпадают с суммированием
по порядкам рассеяния у Аллахвердяна и Наумова, §4 (фазовая функция HG).

| Время | Содержание |
|---|---|
| 0–22 мин | RTE, определения и производные величины, вывод и сохранение числа |
| 22–27 мин | Однородное поглощение как множитель $e^{-\alpha t}$ |
| 27–45 мин | Направленная вспышка: точный центр, второй момент, ковариация и ширина |

## Лекция 2. Диффузионное приближение

Вывод из RTE: точные балансы плотности и потока, угловое замыкание $P_1$
и медленная эволюция потока. В принятом ведущем пределе поглощение слабое:
$D=v_g/[3\mu_s(1-g)]$, а $\alpha=v_g\mu_a$ остаётся реакционным членом.
Решения выводятся по шагам; пределы применимости сравниваются с водой
нейтринного телескопа.

| Время | Содержание |
|---|---|
| 0–15 мин | Балансы плотности и потока, замыкание, закон Фика |
| 15–21 мин | Телеграфное уравнение и скорость фронта $v_g/\sqrt3$ |
| 21–31 мин | Мгновенная вспышка: решение через Фурье и проверка |
| 31–35 мин | Постоянный точечный источник |
| 35–40 мин | Направленная вспышка и сравнение с точными моментами |
| 40–45 мин | Масштабы, причинный фронт, вода телескопа |

Графики используют безразмерные транспортные масштабы. Для воды телескопа
на 450 нм приведён образец BaikalWater, используемый LightHit и NTSim:
μ_a = 0.076 м⁻¹, μ_s = 0.019 м⁻¹, n_g = 1.371324; для HG отдельно задано g = 0.9.
Отсюда транспортная длина 526 м, а μ_a / [μ_s(1−g)] = 40.
Синтетическая среда встроенного `lighthit-demo` помечена отдельно.

Этот план предполагает выбор основных табов. Полный устный разбор всех
выкладок требует дополнительного времени.

## Лекция 3. Изотропный источник: точное решение

Изотропная вспышка и произвольная индикатриса (HG): цепная дробь по гармоникам
для $\tilde\Phi(k,\omega)$, порядки рассеяния, порядок 1 в $(r,t)$ как интеграл
по эллипсоиду с полной фазовой функцией и рисунком геометрии, обрыв всей цепочки
на $\ell=1$ — телеграфное уравнение, затем отдельный диффузионный предел. Частный случай $g=0$: $\tilde\Phi=NA/(1-\mu_sA)$,
$A=\arctan(k/d_0)/k$, полюс и формула с $\ln$. Лазер в LightHit: время расчёта,
event viewer (`assets/03_isotropic_exact/laser-viewer.html`, синтетический детектор)
и исследование света на 200–300 м (рисунки: `generate_figures.py`, данные
`laser_data.npz`). На последнем слайде — физические проверки, сходимость по
гармоникам и численные сравнения с явно указанной относительной ошибкой.
Замеры, viewer и рисунки дальних путей относятся к явно указанной синтетической
среде; новый практический расчёт на 450 нм использует BaikalWater.

## Задачи и практика LightHit

К первым трём лекциям добавлены 19 задач без решений. Общие условия хранятся
в `_includes/exercises/`, отдельные страницы и общий список — в `ru/exercises/`.
Каждая карточка лекции ведёт к её задачам и практическому примеру.

`ru/practice/` — руководство: установка опубликованного LightHit 0.3.0a4,
среда и моменты (лекция 1), RTE против диффузии (2), вспышка, временные бины и
учебный приёмник (3). Скрипты — в `examples/`; общие параметры —
`course_medium.py`. Все примеры запускаются без внешних калибровок.

```bash
python -m pip install "lighthit[accelerate,viewer]==0.3.0a4" matplotlib
lighthit-selftest
python examples/01_medium.py
python examples/02_diffusion.py
python examples/03_flash.py
```

`--refine` в примерах 2–3 проверяет численное уточнение. Скрипты сохраняют JSON,
CSV и SVG в `.work/practice/`. Сборка создаёт скачиваемый архив примеров в
`_site/downloads/`. Статические рисунки практики воспроизводятся командами:

```bash
python examples/02_diffusion.py --output ru/practice/assets/02_diffusion
python examples/03_flash.py --output ru/practice/assets/03_flash
```

На сайте публикуются SVG этих двух запусков. Спектры, CSV и JSON остаются
локальными результатами вычислений.

## Оформление и сборка

Локальные копии темы, логотипа, footer-скрипта и подключения аналитики взяты
из канонических `neutrinohit-map/assets/reveal/` и `neutrinohit-map/analytics/`;
обновляются командой `make sync-shared`. Формат 1600×1000 (16:10) и последовательные табы
следуют `neutrinophysics/introduction/ru/slides` и `stat-course/ru/slides`.

Из папки курса:

```bash
make site      # страница курса, лекции и дополнения в _site/
make preview   # локальный предпросмотр
make clean
```

Исходники: `index.qmd` (страница курса), `ru/slides/01_definitions.qmd`,
`ru/slides/02_diffusion.qmd`, `ru/slides/03_isotropic_exact.qmd`.
Результаты: одноимённые HTML в `_site/`.

Footer слайдов ведёт на страницу курса `https://neutrinohit.github.io/rte_lectures/`.
Адрес зарегистрирован в `neutrinohit-map/scripts/reveal_context_targets.json`;
на карте NeutrinoHit у курса карточка с якорем `#light-propagation`.

## Иллюстрации

Все математические подписи в схемах и элементах управления набраны в LaTeX.
`math-helper.js` обеспечивает их отрисовку и обновление при взаимодействии.

Источники показаны статично: однонаправленный, изотропный и черенковский
сегмент. В выводе баланса поток через границу показан на неподвижном объёме
с отмеченными площадками входа и выхода. Каждая подпись соответствует
величине в балансе.

Анимации оставлены для поглощения и изменения направления при рассеянии.
При открытии своего слайда и таба они автоматически запускаются с начала
и повторяются циклически. При скрытии таба или уходе со слайда движение
останавливается. Кнопок и временной шкалы у этих анимаций нет. Схемы отклика ОМ и временных бинов
позволяют изменять ориентацию и окно наблюдения.

## Литература

S. R. Arridge, J. C. Schotland, [Optical tomography: forward and inverse
problems](https://arxiv.org/abs/0907.2586), §3.5: асимптотический вывод
диффузии (3.73)–(3.75) и фундаментальное решение (3.83)–(3.85), здесь при
$\omega=0$. Обозначения приведены к принятой в курсе плотности числа фотонов.

В. Аллахвердян, Д. В. Наумов, [Infinite series solution of the time-dependent
radiative transfer equation in anisotropically scattering media](https://arxiv.org/abs/2401.15698),
J. Quant. Spectrosc. Radiat. Transf. **326**, 109126 (2024),
[doi:10.1016/j.jqsrt.2024.109126](https://doi.org/10.1016/j.jqsrt.2024.109126),
§4, формулы (40)–(54): моменты направленной вспышки для фазовой функции HG.
Уравнения для моментов и ширины $\Sigma$ в лекции 1 выведены из RTE
и с ними совпадают.
